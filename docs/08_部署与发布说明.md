# ClipLens 部署与发布说明

| 项目名称 | ClipLens |
|---------|----------|
| 版本 | v1.0 |
| 日期 | 2026-08-06 |

---

## 1. 运行环境要求

| 项 | 要求 |
|----|------|
| 操作系统 | Windows 10+ / macOS 12+ / Linux (X11/Wayland) |
| Python | 3.10+ |
| 内存 | 建议 8GB+ |
| 磁盘 | 视图库规模（缩略图+向量） |
| GPU（可选） | NVIDIA + CUDA 加速推理 |

---

## 2. 依赖清单

```
PySide6>=6.6        # GUI 框架
Pillow>=10.0        # 图像处理
cn_clip             # 多模态模型（Chinese-CLIP，非标准 PyPI 包，见下方安装）
torch>=2.0          # 深度学习框架
torchvision>=0.15   # 图像处理（配合 torch）
onnxruntime>=1.16   # 可选 CPU 推理
lancedb>=0.4        # 向量数据库
send2trash>=1.8     # 系统回收站
psutil>=5.9         # 内存监控
```

### 安装命令

```bash
pip install PySide6 Pillow lancedb send2trash onnxruntime psutil
# 若需 GPU
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118

# Chinese-CLIP 需从官方 GitHub 安装（非标准 PyPI 包）：
pip install "cn_clip @ git+https://github.com/OFA-Sys/Chinese-CLIP.git"
# 或克隆后本地安装：
#   git clone https://github.com/OFA-Sys/Chinese-CLIP.git
#   cd Chinese-CLIP && pip install -e .
```

## 3. 本地运行

### 3.1 源码运行

```bash
git clone <repo>
cd ClipLens
pip install -r requirements.txt
python main.py
```

### 3.2 环境变量（可选）

| 变量 | 说明 |
|------|------|
| `CLIPLENS_HOME` | 覆盖全局数据目录 `~/.cliplens` |
| `CLIPLENS_MODEL_PATH` | 指定 Chinese-CLIP 权重路径 |

---

## 4. 打包发布

### 4.1 PyInstaller 单文件打包

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed \
  --name ClipLens \
  --add-data "models;models" \
  main.py
```

### 4.2 目录结构（打包产物）

```
dist/
└── ClipLens.exe (或 ClipLens.app / ClipLens)
```

### 4.3 注意点

- 模型权重体积较大（数百 MB），可改为首次运行时下载到 `~/.cliplens/models/`。
- GUI 应用使用 `--windowed`，避免弹出控制台。
- 需附带 `send2trash` 原生扩展。

### 4.4 模型下载体验设计

| 场景 | 行为 |
|------|------|
| 首次启动（无模型） | 弹出下载引导，显示进度条（已用/总量字节、速度） |
| 下载中断 | 支持断点续传（记录已下载字节）；失败可"重试" |
| 无网络/下载失败 | 提供"离线模式"：禁用语义检索，仅浏览已索引图片 |
| 已有模型 | 设置中支持手动指定 `CLIPLENS_MODEL_PATH` 或选择本地权重目录 |
| 模型校验 | 下载完成后校验文件哈希与版本，失败自动回滚 |

> 模型目录约定：`~/.cliplens/models/clip/`，可用 `CLIPLENS_MODEL_PATH` 环境变量覆盖。

## 6. 首次使用流程

1. 安装依赖 / 运行安装包。
2. 首次启动，自动初始化全局库 `~/.cliplens/app.db`。
3. 新建项目，指定数据目录。
4. 选择图片来源目录，触发扫描建库。
5. 开始浏览 / 检索。

## 7. 升级与兼容

### 7.1 Schema 版本管理

- 全局库 `app.db` 与各项目 `metadata.db` 均在 `system_config` 表中维护 `schema_version` 键。
- **初始值**：`schema_version = 1`。
- **迁移时机**：应用启动、打开项目时检测版本；若数据库版本 < 当前代码期望版本，按序执行迁移脚本。

### 7.2 迁移策略

- 迁移脚本采用**增量、幂等**设计：`migrations/0001_init.sql`、`migrations/0002_add_status.sql` 等，每个脚本以"当前版本 + 1"为后缀命名。
- 执行流程：
  1. 读取当前 `schema_version`。
  2. 循环执行版本号大于当前的迁移脚本，每个脚本包在事务中。
  3. 每个脚本成功执行后将 `schema_version` 更新为对应版本。
  4. 脚本失败则回滚事务，保持原版本，应用提示"数据库升级失败"。

### 7.3 `system_config` 归属约定

- `schema_version`、`thumbnail_size` 等**项目级配置**存于各项目 `metadata.db` 的 `system_config` 表。
- 全局库 `app.db` 同样有 `system_config` 表，存放 `app_schema_version` 等全局配置。
- 两处 `system_config` 结构相同（`key` / `value`）。

### 7.4 兼容保证

- 保持图片路径不变原则，升级不影响原图。
- 迁移仅增补字段/索引，不做破坏性变更，保证旧数据可读。
- 缩略图/向量库升级失败可触发重建索引，不阻塞图片浏览。

---

## 8. 备份与恢复

- **备份**：拷贝项目 `.cliplens/` 目录即可备份元数据、向量与缩略图。
- **恢复**：拷回目录后在 ClipLens 中重新打开项目。
- **原图备份**：原图由用户自行管理，ClipLens 不迁移图片。
