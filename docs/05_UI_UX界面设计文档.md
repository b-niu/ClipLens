# ClipLens UI/UX 界面设计文档

| 项目名称 | ClipLens |
|---------|----------|
| 版本 | v1.0 |
| 日期 | 2026-08-06 |

---

## 1. 设计原则

1. **极简主义**：背景纯粹，突出图片内容本身。
2. **沉浸式浏览**：大面积网格视图，工具按需浮现。
3. **高效操作**：全键盘快捷键支持，减少鼠标移动。
4. **主题适配**：支持浅色/深色主题。

### 2.1 侧边栏（Sidebar）

| 区块 | 内容 |
|------|------|
| 项目列表 | 当前所有 Project，点击切换，支持新建/重命名/删除 |
| 过滤器 | 评分星级、标签多选、日期范围 |
| 回收站 | 软删除图片的独立视图 |

### 2.2 网格视图（Main Grid）

- 瀑布流/网格布局，卡片显示缩略图。
- 卡片角标：左下角文件名（悬停显示），右上角星级（可点）。
- 选中态：高亮边框 + 半透明遮罩。

### 2.3 预览面板（Preview）

- `Space` 或双击打开大图预览。
- 顶部显示路径、尺寸、评分、标签信息。
- 提供"添加标签"入口（见 3.5 标签管理）。

### 2.4 设置面板（Settings）

- **模型**：显示模型状态（未下载/已就绪）、下载进度、手动指定模型权重路径。
- **缩略图**：缓存容量上限、是否启用懒加载。
- **外观**：浅色/深色主题切换。
- **快捷键**：查看/自定义快捷键映射。

### 2.5 状态栏（Status Bar）

- **图片统计**：共 X 张 | 选中 Y。
- **索引进度**：索引中 N/M 张，进度条。
- **内存占用**：每 2 秒采样一次当前进程 RSS（`psutil`），格式 `内存 456MB / 512MB`（相对阈值）。超过阈值（如 500MB）时以红色 + 警示图标提示"内存偏高"。
- **检索耗时**：最近一次检索耗时（ms），用于感知性能。

## 3. 交互流程

### 3.1 项目切换
1. 用户点击侧边栏项目。
2. 系统加载该项目数据库与向量库。
3. 网格刷新为该项目的图片。

### 3.2 语义检索
1. 用户输入自然语言，回车。
2. 系统编码文本 → 检索向量 → 组合过滤。
3. 网格按相似度排序展示结果。

### 3.3 批量评分
1. 用户多选图片。
2. 按 `1`~`5` 设置评分。
3. 卡片角标即时刷新，写入数据库。

### 3.4 删除流程
1. 选中图片按 `Delete` → 软删除，界面隐藏。
2. 回收站视图可"恢复"或"彻底删除"。
3. 彻底删除走系统回收站。

### 3.5 标签管理流程
1. 打开图片预览面板，点击"添加标签"按钮。
2. 输入标签名并回车（支持多个，逗号分隔），即时写入数据库。
3. 预览面板标签区显示已有标签，点击"×"移除。
4. 侧边栏"标签"过滤器可多选过滤；勾选标签后网格仅显示含这些标签的图片。

### 3.6 路径重映射流程（死链处理）
1. 打开项目时检测到失效路径，弹出"重新定位"引导。
2. 用户选择一个新根目录。
3. 系统将失效路径的旧前缀映射为新前缀，批量更新 `file_path`。
4. 映射失败的项标记为死链（标红），可忽略或从索引移除。

### 3.7 模型下载流程
1. 首次启动检测到无本地模型权重，弹出下载引导。
2. 显示下载进度条与已用/总量（字节）。
3. 下载失败：提供"重试"与"离线模式"（禁用检索，仅浏览已索引图片）。
4. 支持在设置中手动指定已存在的模型权重路径。

## 4. 视觉规范

| 元素 | 规范 |
|------|------|
| 主色 | 中性灰 / 品牌色（建议 #4A90D9） |
| 背景 | 浅色 `#F5F5F5`，深色 `#1E1E1E` |
| 字体 | 系统默认，正文 13px，标题 15px |
| 卡片圆角 | 6px，间距 8px |
| 缩略图 | 等比缩放，居中裁剪 |

### 4.1 状态视觉

| 状态 | 表现 |
|------|------|
| 选中 | 蓝色高亮边框 |
| 已评分 | 右上角星星点亮 |
| 已删除(软) | 网格中隐藏，仅回收站可见 |
| 损坏/死链 | 红色角标提示 |

## 5. 快捷键汇总

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + 点击` | 多选 |
| `Shift + 点击` | 范围选择 |
| `Ctrl + A` | 全选 |
| `1`~`5` | 批量评分 |
| `0` | 清除评分（选中图） |
| `Delete` / `Backspace` | 软删除 |
| `Space` | 预览大图 |
| `Esc` | 关闭预览对话框 / 取消当前操作（清除评分改用 `0`） |
| `Ctrl + N` | 新建项目 |
| `Ctrl + O` | 打开项目 |
| `Ctrl + F` | 聚焦搜索框 |
| `Ctrl + Shift + Del` | 彻底删除 |
