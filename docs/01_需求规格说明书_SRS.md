## 1. 引言

### 1.1 编写目的
本文档定义 ClipLens 的功能性与非功能性需求，作为设计、开发、测试与验收的依据。面向对象：产品经理、架构师、开发工程师、测试工程师。

### 1.2 项目背景
ClipLens 是一款面向个人及专业用户的本地 AI 智能图片浏览与管理工具。基于 **Python + PySide6** 开发，集成 **Chinese-CLIP** 多模态模型与 **LanceDB / SQLite**，实现基于自然语言文本的本地图片跨模态检索、流式网格浏览、批量打分、智能筛选与安全删除管理。

软件以 **Project（项目）** 为核心组织单元：每个项目拥有独立的数据目录（数据库 + 缩略图），图片文件保持原始路径不变。

### 1.3 术语定义

| 术语 | 说明 |
|------|------|
| Project | 项目，ClipLens 数据隔离与组织的基本单位 |
| 数据目录 | 项目专属 `.cliplens/` 目录，存放数据库与缩略图 |
| Embedding | 图像/文本经 CLIP 编码得到的高维向量 |
| 软删除 | 仅在数据库标记删除，不动磁盘文件 |
| 死链 | 数据库存在但磁盘文件已失效的记录 |

## 2. 系统总体描述

### 2.1 运行环境

| 项 | 要求 |
|----|------|
| 操作系统 | Windows 10+ / macOS 12+ / Linux (X11/Wayland) |
| Python | 3.10+ |
| 硬件 | 建议 8GB+ 内存；有 NVIDIA GPU（CUDA）可加速 |
| 显示 | 1080p 及以上 |

### 2.2 用户角色

| 角色 | 描述 |
|------|------|
| 普通用户 | 浏览、检索、打分、删除图片 |
| 高级用户 | 创建/管理多个项目、批量操作 |

### 2.3 功能需求总览

| 编号 | 功能域 | 说明 |
|------|--------|------|
| FR-1 | 项目管理 | 项目创建/打开/切换/删除/分享 |
| FR-2 | 图库扫描 | 增量扫描、索引建库 |
| FR-3 | 多模态检索 | 自然语言文本检索图片 |
| FR-4 | 网格浏览 | 虚拟化瀑布流浏览 |
| FR-5 | 批量操作 | 批量打分、多选、预览 |
| FR-6 | 回收站 | 软删除、恢复、物理删除 |
| FR-7 | 标签管理 | 图片打标与按标签过滤 |

## 3. 功能性需求

### 3.1 FR-1 项目管理

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| FR-1.1 | 用户可创建项目，指定名称与数据目录 | P0 |
| FR-1.2 | 用户可打开已存在的项目 | P0 |
| FR-1.3 | 用户可在项目间切换，检索限定在当前项目 | P0 |

### 3.2 FR-2 图库扫描

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|

| FR-2.2 | 系统增量扫描，识别 NEW/UPDATED/MISSING | P0 |
| FR-2.3 | 系统自动生成缩略图（WebP，懒加载） | P0 |
| FR-2.4 | 系统自动提取 CLIP 向量并入库 | P0 |

### 3.3 FR-3 多模态检索

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| FR-3.1 | 用户输入自然语言文本，检索相关图片 | P0 |

| FR-3.3 | 检索结果按相似度排序返回 Top-N | P0 |

### 3.4 FR-4 网格浏览

| 需求编号 | 需求描述 | 优先级 |

## 4. 非功能性需求

| 编号 | 类别 | 需求 | 指标 |
|------|------|------|------|
| NFR-1 | 性能 | 检索响应 | 单项目 10 万张，总耗时 < 100ms |
| NFR-2 | 性能 | 索引吞吐 | CPU 20~40 张/秒；GPU 150+ 张/秒 |
| NFR-3 | 性能 | 界面帧率 | 滚动 60 FPS |
| NFR-4 | 性能 | 内存占用 | < 500MB |
| NFR-5 | 安全 | 隐私 | 完全本地化，无网络上传 |
| NFR-6 | 安全 | 防误删 | 物理删除走系统回收站 |
| NFR-7 | 可靠性 | 容错 | 损坏图片/死链/项目损坏均有处理 |
| NFR-8 | 可用性 | 易用 | 快捷键支持、响应式界面 |

## 5. 约束与假设

- 图片格式支持：JPEG/PNG/WebP/GIF/BMP（Pillow 支持范围）
- 单项目建议图片规模：≤ 10 万张
- 假定用户图片文件路径保持稳定，移动后需重新定位
- 模型推理依赖本地 Chinese-CLIP 权重文件
