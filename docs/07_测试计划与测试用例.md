# ClipLens 测试计划与测试用例

| 项目名称 | ClipLens |
|---------|----------|
| 版本 | v1.0 |
| 日期 | 2026-08-06 |

---

## 1. 测试目标

验证 ClipLens 的功能正确性、性能达标、健壮性与安全性，确保 10 万张图片场景下稳定运行。

---

## 2. 测试环境

| 项 | 配置 |
|----|------|
| 系统 | Windows 11 / macOS 13 / Ubuntu 22.04 |
| Python | 3.10 / 3.11 |
| GPU（可选） | NVIDIA + CUDA 用于性能测试 |
| 样本数据 | 构造 1000 ~ 100,000 张混合图片 |

---

## 3. 测试级别

| 级别 | 范围 |
|------|------|
| 单元测试 | 模块级（Project/Search/Trash/Scanner） |
| 集成测试 | 模块协作、数据库读写 |
| 系统测试 | 端到端 GUI 流程 |
| 性能测试 | 吞吐、响应、内存 |
| 安全测试 | 防误删、隐私 |

---

## 5. 性能测试用例

### PT-01 索引吞吐

| 项 | 指标 |
|----|------|
| CPU (ONNX-INT8) | 20~40 张/秒 |
| GPU (CUDA) | 150+ 张/秒 |

### PT-02 检索响应

| 项 | 指标 |
|----|------|
| 10 万张 | 文本编码 + 向量检索 < 100ms |

### PT-03 内存占用

| 项 | 指标 |
|----|------|
| 长时间浏览 | < 500MB |

## 6. 安全测试用例

### ST-01 防误删
- 确认物理删除必须走系统回收站，绝不直接删除文件。
- 软删除阶段文件仍在磁盘。

### ST-02 隐私
- 确认无任何网络请求，所有数据处理本地完成。
- 通过抓包验证无外发数据。

---

## 7. 异常与容错测试

| 用例 | 期望 |
|------|------|
| 损坏图片解码失败 | 标记 CORRUPTED，跳过向量，不崩溃 |
| CUDA OOM | 自动降低 batch_size 或降级 CPU |
| 死链 | 提示清理或标红 |
| 项目数据损坏 | 提示重建索引或恢复 |
| 项目迁移路径失效 | 支持重新定位目录 |
